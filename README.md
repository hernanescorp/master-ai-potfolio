# Master AI Engineering Portfolio

This repository contains my work from a Master's in Artificial Intelligence Engineering.

## Purpose

Build a professional AI and Data Science portfolio with reproducible notebooks, applied projects, reusable source code, tests, and cloud execution notes.

## Main Structure

- `docs/`: methodology, setup notes, standards, glossary, and roadmap.
- `notebooks/`: study notebooks organized by subject.
- `projects/`: applied portfolio projects.
- `datasets/`: shared data areas for raw, processed, and sample data.
- `src/`: reusable Python modules.
- `tests/`: automated tests.
- `databricks/`: Databricks-specific configuration notes, jobs, workflows, and bundles.
- `images/`: screenshots, diagrams, and result images.
