# Databricks Setup

Azure Databricks is used as a cloud execution environment for notebooks, Spark jobs, and scalable data workflows.

## Architecture

Azure provides the compute resources and Databricks manages Spark execution, cluster orchestration, and notebook workflows.

## Execution Flow

1. Develop locally in VS Code or Jupyter.
2. Version notebooks and code with GitHub.
3. Run selected workflows in Databricks.
4. Store results and notes back in the repository.
