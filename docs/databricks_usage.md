# Databricks Usage in This Project

In this project, Azure Databricks is used as a cloud-based environment to execute data analysis and machine learning workflows.

## Why Databricks?

- Scalable execution
- Real-world data science environment
- Integration with Spark

## Workflow

1. Develop notebooks locally (VS Code / Jupyter)
2. Execute in Databricks cluster
3. Analyze results
4. Version control with GitHub

## Cluster Setup

A single-node cluster is used to simulate a distributed environment while keeping costs low.

## Key Benefit

Allows transitioning from local experimentation to cloud-based data processing.
